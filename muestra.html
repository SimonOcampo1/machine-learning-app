{ Controles }

Outlined, siempre

El sistema no tiene botones rellenos. La única escalación cromática permitida es el borde de gradiente del CTA principal, y va uno por vista.

Las opciones de ejercicio son el mismo pill, en sus tres estados:

Feedback correcto: borde completo de 1px, nunca border-left.
Feedback incorrecto: el mismo componente, otro color de estado.
00

{ Fase 0 }

Piso

Nadie toca un modelo antes de saber qué es un vector. Este párrafo chequea medida de lectura, interlineado y color de cuerpo: var(--ink) sobre var(--bg), nunca el color de fase.

NotaCallout normal, fondo --fase-tint y borde --fase.
y = β₀ + β₁x + ε
CuidadoAdvertencia — siempre naranja, sin importar la fase.
ClaveConfirmación — siempre verde, sin importar la fase.
01

{ Fase 1 }

Aprender de los datos

Qué significa que una máquina aprenda. El color de esta fase es el lila; compará su intensidad contra el azul de arriba.

NotaEl mismo componente, otro color: solo cambia --fase.
Error clásicoLa paleta de gsap.com no tiene rojo, así que este sabor va en rosa. El rótulo es lo que porta la severidad, no el color.

{ Fase 3 }

Clasificación

Predecir una categoría. El naranja de esta fase coincide con el del callout warn: son el mismo naranja por diseño, no un accidente.

NotaCallout normal — mismo naranja que un warning, pero por ser la fase, no la severidad.
ClaveEl callout ok sigue siendo verde acá, no naranja.
